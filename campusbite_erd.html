CampusBite Database Schema - ERD Diagram

Database Overview

  • Database Name: campusbite
  • Engine: InnoDB
  • Character Set: utf8mb4
  • Collation: utf8mb4_general_ci
  • Generated: 2026-08-07

Tables and Relationships

1. CANTEENS (Master Table)

Field Type Key Description
canteen_id INT(11) PK Primary Key, Auto-increment
name VARCHAR(100) Canteen name
location VARCHAR(150) Canteen location
status ENUM('open','closed') INDEX Current status

2. STUDENTS (User Table)

Field Type Key Description
student_id INT(11) PK Primary Key, Auto-increment
university_id VARCHAR(50) UNIQUE University ID (unique)
password VARCHAR(255) Hashed password
full_name VARCHAR(100) Student full name
department VARCHAR(50) Department (nullable)

3. CANTEEN_OWNERS (User Table)

Field Type Key Description
owner_id INT(11) PK Primary Key, Auto-increment
university_id VARCHAR(50) UNIQUE University ID (unique)
password VARCHAR(255) Hashed password
full_name VARCHAR(100) Owner full name
canteen_id INT(11) FK Foreign key to canteens (nullable)

4. FOOD (Child Table)

Field Type Key Description
food_id INT(11) PK Primary Key, Auto-increment
canteen_id INT(11) FK Foreign key to canteens
food_name VARCHAR(100) INDEX Food item name
price DECIMAL(8,2) Food price
stock INT(11) Available stock (default: 0)
available TINYINT(1) INDEX Availability status (default: 1)

5. REVIEWS (Child Table)

Field Type Key Description
review_id INT(11) PK Primary Key, Auto-increment
canteen_id INT(11) FK Foreign key to canteens
user_id INT(11) Legacy field (nullable)
student_id INT(11) FK Foreign key to students (nullable)
student_name VARCHAR(100) Student name (denormalized)
university_id VARCHAR(50) University ID (denormalized)
department VARCHAR(50) Department (denormalized)
rating TINYINT(4) Star rating (1-5)
comment TEXT Review comment
created_at TIMESTAMP INDEX Creation timestamp
updated_at TIMESTAMP Last update timestamp

6. COMPLAINTS (Child Table)

Field Type Key Description
complaint_id INT(11) PK Primary Key, Auto-increment
canteen_id INT(11) FK Foreign key to canteens
user_id INT(11) Legacy field (nullable)
student_id INT(11) FK Foreign key to students (nullable)
student_name VARCHAR(100) Student name (denormalized)
university_id VARCHAR(50) University ID (denormalized)
department VARCHAR(50) Department (denormalized)
message TEXT Complaint message
created_at TIMESTAMP INDEX Creation timestamp
updated_at TIMESTAMP Last update timestamp

Relationship Details

Relationship Type Description
canteen_owners.canteen_id → canteens.canteen_id One-to-One/Many Each owner manages one canteen
food.canteen_id → canteens.canteen_id Many-to-One Each canteen has many food items
reviews.canteen_id → canteens.canteen_id Many-to-One Each canteen has many reviews
complaints.canteen_id → canteens.canteen_id Many-to-One Each canteen has many complaints
reviews.student_id → students.student_id Many-to-One Each student can write many reviews
complaints.student_id → students.student_id Many-to-One Each student can submit many complaints

Key Legend

  • PK = Primary Key
  • FK = Foreign Key
  • UNIQUE = Unique constraint
  • INDEX = Indexed field

Notes

  • user_id in reviews and complaints tables is a legacy field kept for backward compatibility
  • student_id is the current foreign key linking to students table
  • The database was migrated from a single users table to separate students and canteen_owners tables
