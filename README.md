# CampusBite

CampusBite is a web-based platform that helps university students compare food items, prices, availability, and reviews across multiple campus canteens.

## Features

- View menus from all canteens
- View food availability
- Compare food prices
- Submit food reviews
- Submit complaints
- Responsive interface

## Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript

## Database

Import `database/campusbite.sql` into MySQL.
